Built from the same list as the menus
How this would work on the real site: the menus, the subject tiles and the sitemap are all drawn from one list (one small JavaScript file). Adding a new section — e.g. KS3 — means adding it to that list once, and it appears in the top menu, the mobile menu and the sitemap on every page. The Teachers menu only shows for teacher and admin logins. Inside a subject, the existing left-hand unit menus stay as they are.
